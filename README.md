This is a tool we believe would be helpful for informing the decision making of a defensive coordinator. With the help of Kiro we have developed a machine learning model that predicts and ranks the defensive performance of different coverages for different offensive setups and contexts. After the individual inputs the context, the model quantifies defensive success for different downs based on yards or first downs gained from different downs. It then runs this with 13 features to calculate based on past performance which coverage and coverage type would give the best chance of defensive success. The code is in model script.
